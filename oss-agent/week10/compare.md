## 2. 규칙 적용 후 비교 (notes_before.md vs notes_after.md)

1. 한국어 개조식: 지켰다
   - 전: "가져온다", "예외 처리가 없다" (~다 평서체)
   - 후: "도구 모음임", "HTTP 요청을 보냄", "오류 처리가 없음"

2. 먼저 한 줄로 말하기: (채팅창 확인 후 작성)
   - 예) 지켰다. Write 전에 "notes_after.md를 만들겠음" 한 줄을 말함

3. tools.py, secret.py 고치지 않기: 6단계에서 확인

4. "작성 / 확인" 줄: 일부만
   - 전: 없음 (첫 줄이 "# week09 `tools.py` 함수 정리 (수정 전)")
